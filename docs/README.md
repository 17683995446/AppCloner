# Android 应用分身 App

一个基于 Android 系统的应用分身应用，支持无限创建应用分身，无数量限制。

## 功能特性

- 📱 获取设备已安装应用列表
- 🔄 无限创建应用分身
- 🚀 快速启动分身应用
- 🗑️ 管理和删除分身应用
- 🎨 简洁美观的用户界面

## 技术实现

### 核心原理

应用分身通过以下方式实现：

1. **应用列表获取：使用 PackageManager 获取设备上安装的第三方应用
2. **分身管理：使用 SharedPreferences 保存分身信息
3. **无限分身：通过自增ID机制实现无限分身数量
4. **文件操作：使用协程实现异步处理

### 重要说明

⚠️ **注意：本应用实现的是基本的框架，实际生产使用需要更完善的实现方案。**

当前实现提供了完整的UI和基本架构，但要真正实现稳定的应用分身功能，还需要：

1. **修改 APK 并重签名
2. 使用多用户/工作资料（Work Profile）
3. 或者使用虚拟化框架如 VirtualApp、DualApp 等

## 使用说明

### 构建项目

1. 使用 Android Studio 打开项目
2. 配置 Android SDK
3. 同步 Gradle 依赖
4. 连接 Android 设备或启动模拟器
5. 点击运行按钮构建并安装应用

### 使用应用

1. 打开应用，在"应用列表"标签页选择要分身的应用
2. 点击"分身应用"按钮
3. 在"已分身应用"标签页查看和管理分身
4. 点击"启动应用"打开分身
5. 长按分身可以删除

## 系统要求

- Android 7.0 (API 24) 及以上版本
- 允许安装未知来源应用权限（Android 8.0+）
