## 🔧 技术栈

- **语言**: Kotlin
- **架构**: MVI + Clean Architecture
- **DI**: Hilt
- **数据库**: Room
- **异步**: Coroutines + Flow
- **UI**: ViewBinding → Jetpack Compose
- **后台**: WorkManager
- **测试**: JUnit + MockK + Espresso
